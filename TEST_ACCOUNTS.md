## How to Test

1. **Start XAMPP:**
   - Make sure Apache and MySQL are running

2. **Access the Application:**
   ```
   http://localhost/isp-management-system/login
   ```

3. **Login as Admin:**
   - Use admin@isp.com / admin123
   - Explore admin dashboard, customer management, network monitoring
   - View network devices and their status
   - Check billing and inventory sections

4. **Logout and Login as Client:**
   - Use client@isp.com / client123
   - View dashboard with usage statistics
   - Check billing and unpaid invoice
   - Browse service plans and add-ons
   - Test support ticket system
   - Update account settings

## Development Notes

- All passwords are hashed using Laravel's Hash facade
- User roles are stored in the `role` column (admin/client)
- Clients have associated Customer profiles
- Sample data is automatically generated by TestAccountsSeeder
- To regenerate test data:
  ```bash
  php artisan migrate:fresh
  php artisan db:seed --class=TestAccountsSeeder
  ```

## Middleware Protection
